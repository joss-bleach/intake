## What it shows

Same modal sheet chrome as the input screen (warm off-white background, system Live Activity pill
overlapping the status bar, X close top-right) but the card has swapped roles entirely: it's now a tall
grey rounded panel with a perforated top edge — a row of small cream dots, like a ticket or receipt tear
line — holding a single centred illustration. A gradient noodle-and-bowl icon (soft pink-to-orange steam
rising off a grey-to-orange bowl, blue-purple shadow beneath) sits mid-panel, roughly food-themed but not
tied to whatever was actually typed. Below the panel, small dark-green serif-adjacent text reads
"Identifying foods…" — the only status copy on screen, no progress bar or percentage. The keyboard is
gone; the rest of the screen above and below is empty.

## Why it's here

Shows how this app handles the "AI is thinking" gap: an illustrated placeholder plus a plain-language
present-participle status line ("Identifying foods…"), not a spinner or numeric progress. The
perforated-ticket panel treatment (vs. the plain white card on the input screen) is a distinct visual
move worth noting even though it's not yet clearly a shared "direction" — leaving unsorted until more
processing-state examples turn up.
